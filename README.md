# Peace Intel · Brand kit for PeaceCon

A designer-facing guide to the Peace Intel brand: logo, colour, type, approved copy, the dove imagery, landing page sections and slide guidance, with downloads for slides and print.

Live at https://thatmattgillespie.github.io/peaceintel-peacecon/

`pages/` holds working copies of the brand's reference pages from the design handoff. `downloads/` holds the files. Fonts are Source Serif 4, Barlow and Space Mono, all under the SIL Open Font License.
